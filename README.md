
E-Commerce Sales & Customer Analytics Dashboard
Project Overview
This project presents an end-to-end E-Commerce Sales Analysis solution using Excel, SQL Server (SSMS), and Power BI. The objective is to analyze sales performance, customer behavior, and product performance while creating an interactive business intelligence dashboard.
The dataset was normalized into separate Customer, Product, and Order tables to demonstrate relational database design and efficient data modeling.

Tools & Technologies

Microsoft Excel – Data cleaning, formatting, and pivot table analysis
SQL Server (SSMS) – Database creation, data import, table relationships, SQL queries, and business analysis
Power BI – Data modeling, DAX measures, and interactive dashboard development
Project Workflow
Cleaned and prepared raw sales data in Excel.
Created separate Customer, Product, and Order tables.
Imported data into SQL Server and established primary key and foreign key relationships.
Performed SQL analysis using JOINs, GROUP BY, aggregate functions, window functions, and ranking queries.
Connected SQL tables to Power BI.
Built an interactive dashboard with KPIs, sales trends, customer insights, and product performance.
